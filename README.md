# Guardia Rápida

**Seguridad práctica para cuidar tu Android con claridad y control.**

Guardia Rápida ayuda a revisar señales en aplicaciones instaladas, investigar posibles causas de anuncios que aparecen encima de otras apps y organizar los resultados por categorías. También permite revisar archivos de una carpeta elegida, consultar apps recientes y abrir Play Protect.

### Funciones

- Revisión local de aplicaciones, sin borrar nada automáticamente.
- Componentes del sistema protegidos dentro de la app.
- Selección de archivos y eliminación con confirmación.
- Comprobación básica de enlaces y avisos periódicos opcionales.
- Interfaz nativa, iconos personalizados y tamaño ajustable.

### Descargas

Las versiones de prueba están disponibles en [Releases](https://github.com/realityxv/guardia-rapida/releases). Android 8 o superior.

> Está en desarrollo. No sustituye a un antivirus completo ni garantiza detectar todos los riesgos. Algunas funciones dependen de Android y del fabricante.

Este repositorio distribuye las APK de prueba; no publica el código fuente.
